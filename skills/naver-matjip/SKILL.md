# naver-matjip

웹 검색으로 블로그 글을 긁어 "걸리는 대로" 추천하지 말고, 이 스킬의 스크립트로 숫자 근거가 있는 후보를 먼저 뽑는다.

## 실행

이 스킬 폴더의 `scripts/matjip.py` 를 실행한다(파이썬 3.9+, 표준 라이브러리만).

```bash
python3 scripts/matjip.py <지역> [--type 음식종류] [--menu 메뉴] [--want "조건"] [--open-now] [--max-price 만원] [--top 5] [--json]
```

- `<지역>`: 사용자가 말한 동네·역 이름. 예) 성수동, 을지로, 강남역
- `--type`: 음식 종류가 있으면. 예) 한식, 고깃집, 파스타
- `--menu`: 특정 메뉴를 찾으면. 예) 크림파스타, 평양냉면 — 리뷰에 그 메뉴 언급이 있는 곳만
- `--want`: 분위기·목적 조건이 있으면 그대로. 예) "조용히 대화하기 좋은 곳", "회식 10명"
- `--open-now`: "지금 갈 수 있는 곳"이면
- `--card 경로.png`: 채팅으로 전할 때. 네이버 플레이스 목록처럼 생긴 카드 이미지(대표 사진·점수·표수·영업 상태)를 저장한다. 이미지를 보내고 식당별 링크는 텍스트로 함께 보낸다(이미지 속 글자는 못 누른다)
- `--max-price`: 예산이 있으면 만원 단위. 예) 3 → 네이버 가격대 '3만원 대'까지(대략적인 표시임을 함께 알린다)
- 기본 기준: 맛 키워드 100표 이상 + 2위 키워드의 2배 이상 (`--min-votes`, `--ratio` 로 조정)

## 결과 전달

- 식당명, 종합 점수, 배수(예: 2.3배), 별점, 근거(예: "대화하기 좋아요 89표", "크림파스타 432회"), 감점 사유, 영업 상태, 네이버 플레이스 링크를 그대로 전한다. 숫자를 지어내지 않는다.
- 첫 줄의 "Jev 판정 적용 / 미연결 / 실패" 표시를 사용자에게도 알린다.
- "⚠️협찬 리뷰 의심"이 붙은 곳은 그 사실을 함께 말한다.
- 통과가 0곳이면 `--ratio 1.5` 로 한 번만 다시 보고, 기준을 낮췄다고 밝힌다.

## 지키는 것

- 네이버 약관상 자동 수집 제약이 있다. 사용자 요청 1건당 1~2회만 실행한다. 반복·대량 조회, 크롤링 용도로 쓰지 않는다.
- 네이버가 내부 데이터 통로를 바꾸면 조회가 깨질 수 있다. "0곳 조회"나 조회 실패가 나오면 도구 고장 가능성을 알리고 일반 검색으로 대체했다고 밝힌다.
